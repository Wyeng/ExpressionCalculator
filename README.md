C++ 表达式计算器
一个基于 C++ 标准库实现的命令行表达式计算器，用于练习 C++ 字符串处理、STL 容器、运算符优先级和异常处理。
功能特性
- 支持四则运算：+、-、*、/
- 根据运算符优先级进行计算
- 支持使用括号改变运算顺序
- 支持整数、小数和一元正负号
- 支持 abs() 绝对值函数
- 支持 sqrt() 平方根函数
- 对除数为零、非法字符、表达式不完整等情况进行异常处理
开发环境
- 编程语言：C++
- 开发工具：Visual Studio
- 使用标准库：<iostream>、<string>、<stack>、<stdexcept>、<cctype>、<cmath>
实现思路
项目使用两个栈完成表达式求值：
- 数字栈 numbers：保存数字以及中间计算结果。
- 运算符栈 operators：保存运算符和左括号。
解析表达式时，程序逐字符读取输入，根据当前字符的类型进行处理：
1. 遇到数字时，解析并将数值压入数字栈。
2. 遇到运算符时，根据运算符优先级决定是否先计算栈顶运算。
3. 遇到左括号时，将其压入运算符栈。
4. 遇到右括号时，计算括号内的运算，直到匹配到左括号。
5. 遇到 abs() 或 sqrt() 时，提取函数参数并计算结果。
6. 对非法输入或计算错误，通过异常进行处理。
主要函数：
函数	作用
calculate(a, b, op)	执行基本的二元四则运算
precedence(op)	返回运算符的优先级
applyTopOperator(numbers, operators)	取出栈顶运算符及操作数并计算
parseNumber(expression, i)	从指定位置解析数字并更新读取位置
evaluateExpression(expression)	解析并计算整个表达式


使用示例
输入：
(2+3)*4
输出：
result: 20
其他示例：
表达式	预期结果
2+3*4	14
abs(-5)	5
sqrt(9)	3
abs(3-8)	5


异常处理
当前实现对一些错误输入进行检查，例如：
- 除数为零，例如 1/0
- sqrt() 参数为负数，例如 sqrt(-4)
- 不支持的函数名
- 非法字符
- 缺少操作数或运算符
- 括号不匹配
当前限制
- 函数参数通过查找右括号提取，暂不支持可靠处理嵌套函数调用，例如 sqrt(abs(-9))。
- 这是一个用于学习和练习 C++ 的命令行项目，后续可继续完善错误提示和测试覆盖。
