# Expression Calculator

A console-based expression calculator implemented in C++.

## Features

- Basic arithmetic: `+`, `-`, `*`, `/`
- Operator precedence
- Parentheses
- Decimal numbers and unary signs
- Mathematical functions: `abs()` and `sqrt()`
- Exception handling for invalid expressions and division by zero

## Environment

- Language: C++
- IDE: Visual Studio
- Standard library: STL

## Example

```text
Please enter an expression: (2+3)*4
result: 20
```

## Current Limitations

- Nested mathematical function calls are not supported yet.
